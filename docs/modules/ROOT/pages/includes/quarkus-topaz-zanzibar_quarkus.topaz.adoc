[.description]
--
The subject type for a relationship whose user type is blank.

quarkus-zanzibar hands over such a relationship on the `quarkus.zanzibar.filter.unauthenticated-user` path, for an endpoint without `@FGAUserType`. The value also applies to a relationship with a blank user type passed to the `RelationshipManager` directly. It does not give an authenticated caller a type. quarkus-zanzibar takes that type from the principal name (`type:id`), then a single role, then `@FGAUserType`. It treats the caller as unauthenticated when none of them gives one.
